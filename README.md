# koala-grist-widgets

Widgets personnalisés pour [Grist](https://www.getgrist.com), prêts à l'emploi : on les ajoute, ils créent eux-mêmes leurs tables.
*Ready-to-use custom widgets for Grist: add one and it creates its own tables.*

## Widgets

| Widget | Description | URL à coller dans Grist |
|---|---|---|
| [Suivi butte de culture](butte-culture/) | Permaculture : schéma butte/jardin, semis, plantation, récolte, journal, rappels | `https://matgn34.github.io/koala-grist-widgets/butte-culture/index.html` |

## Installation (tous les widgets)

1. Dans Grist, ajoute une vue : **Ajouter une page → Ajouter un widget à la page → Personnalisé**.
2. Choisis une table quelconque comme source (le widget n'en a pas besoin, mais Grist en demande une).
3. Dans le panneau de droite : **Personnalisé → URL personnalisée**, colle l'URL du widget.
4. Règle l'accès sur **Accès complet au document**.

Au premier affichage, le widget crée ses tables et ses données de départ.

## Versions
